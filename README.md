# Asteria — Women's Safety Companion

Asteria is a web-based women's safety companion designed to help users access safety tools, locate nearby emergency services, and respond more confidently in potentially unsafe situations.

## ✨ Features

- **Emergency Assistance:** Quick access to emergency calling and SOS-related features.
- **Location Services:** Location-based safety assistance, subject to browser permissions and service availability.
- **Nearby Emergency Services:** Tools to help users locate nearby police stations and other emergency services.
- **User Identity Setup:** An initial screen for entering basic user details.
- **Interactive Map:** Map-based navigation and location visualization.
- **Modern User Interface:** A dark interface with golden visual accents, animations, and responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Mapbox GL JS
- Face API integration, where configured

## 🔐 Privacy and Security

- Grant location permissions only when you are comfortable doing so.
- Never commit secret API keys, access tokens, passwords, or private credentials to GitHub.
- Review how personal information is collected, stored, and used before deploying the application publicly.
- Test emergency and location features before relying on them.

## ⚠️ Important Note

Asteria is a technology-based safety assistance project. It does not replace emergency services. Features may depend on device compatibility, network connectivity, browser permissions, and external services.

Always contact the appropriate local emergency services when immediate assistance is needed.
